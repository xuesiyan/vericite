## 五、复现方式确认

我确认，本作品的以下复现方式已在提交前实际执行并验证通过：

```bash
cd vericite
node cli.mjs demo --all      # 10 个样例全部通过，导出运行证据
node tests/run.mjs           # 回归测试入口，失败返回非零退出码（含 7 项模型通道离线单元检查）
```

环境要求：Node ≥ 20，无第三方运行时依赖，语料已随仓库提供（无需联网）。

可选的模型第二意见通道（已实测，证据见 `evidence/model-channel-{agree,disagree}.json`）：

```bash
AGNES_API_KEY=<赛事发放，勿公开> node cli.mjs audit --text "……" --model
```

**AGH 集成部分的可复现性说明**：AGH 的完整本地发行版在 Windows 上需要 MSVC 工具链编译原生模块 `agnes-system.node`，
在竞赛开发机的环境限制下未能完成该构建。为此我们提供了一条**不依赖原生模块、也不需要模型凭据**的验证路径：

```bash
# 在 agnes-harness 仓库根目录执行
tsx ../vericite/tools/agh-integration.mjs
```

该脚本使用 AGH 本体的插件清单解析器、真实 Cordis 运行时、工具定义校验器与参数校验器，
验证插件装载与工具链执行，结果 55/55 断言通过（证据见 `evidence/agh-integration.json`）。
完整 agent loop（需要 Agnes 账号与模型路由）的复现步骤见 `README.md` §5.3 与 §8。
